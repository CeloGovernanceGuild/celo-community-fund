Notes on each field:

- Receiver Entity is who the proposal is presented to, not who receives the funds.
- Status starts as [DRAFT]. Change it to [FINAL] after the discussion.
- Author(s): every name or alias with its forum handle.
- Type of Request, pick one: Mento Proposal / Network Decisions & Protocol
  Improvements / Smart Contract Changes / Temperature Check / Funding.
- Intent, Funding Category and Funding Request only apply to funding proposals.
- Funding Category, pick the one of the current season: Protocol Development /
  Infrastructure / Partnerships, Comms, Marketing, Events, Programs / Builder
  Programs / Direct Grants / DeFi Flywheel Infrastructure and Incentives /
  Regional Community Growth / Community Operations.
- Funding Request: the amount in the token requested. It can be one or two tokens
  and can be split in several claims, for example
  "55,000 USDm: 28,000 USDm in H1 + 27,000 USDm in H2".
  Check what is available first: https://www.celocommunityfund.xyz
